## 一、阅读论文《面向对话状态追踪的持续提示调优》

#### 1、摘要：

论文首先提出了一个核心问题：一个理想的对话系统应该能够持续学习新技能而不遗忘旧技能，但持续训练模型往往会导致"灾难性遗忘"（Catastrophic Forgetting）。作者提出的解决方案是 Continual Prompt Tuning（持续提示调优），这是一个参数高效的框架：
 • 避免遗忘：只学习和存储每个任务的少量提示 token 嵌入，同时冻结主干预训练模型。
 • 知识迁移：提出了多种技术实现任务间的双向知识迁移：
       前向迁移（从先前任务到当前任务）：持续提示初始化、查询融合、记忆回放
       后向迁移（从后续任务到先前任务）：记忆引导技术
实验在对话状态追踪（DST）任务上进行，证明了该方法在效果和效率上都优于现有最优方法。

#### 2、引言

##### 2.1、研究背景：

传统对话系统研究通常假设数据分布不变，在离线环境下为特定领域开发。但现实情况是，部署后的对话系统需要不断支持新领域和新服务，因此持续学习至关重要

##### 2.2、核心挑战：灾难性遗忘

当神经网络按顺序学习多个任务时，新任务会严重干扰旧任务的表现，这就是灾难性遗忘。

##### 2.3、现有方法的局限：

近期方法通过冻结主干模型，为每个任务训练权重/特征掩码（Mask）或适配器（Adapter)来缓解遗忘，但这些方法计算和存储效率仍不够，同时忽略了任务间的知识迁移

##### 2.4、本文方法：

作者将提示调优（Prompt Tuning）引入持续学习：

• 冻结预训练模型，只为每个任务训练少量软提示 token 的嵌入 

• 提示参数量极少（实验中仅占预训练模型参数的 0.1%）

• 推理时只需切换不同提示即可处理不同任务

与独立训练每个任务提示的做法不同，本文提出的框架支持双向知识迁移：

• 前向迁移：从先前任务学习，帮助当前任务

• 后向迁移：利用后续任务数据，帮助改进先前任务

##### 2.5、贡献总结

1、首次将提示调优用于持续学习，高效避免遗忘

2、探索了基于提示调优的前向和后向知识迁移技术

3、在持续DST任务上验证了方法的优越性能和效率

#### 3、相关工作：方法的理论基础

##### 3.1持续学习:

介绍了三类方法：

 • 排练法（Rehearsal）：存储并回放旧任务样本

• 正则化法（Regularization）：添加额外损失巩固知识

• 架构法（Architectural）：为每个任务引入特定参数，固定旧任务参数（本文方法属于此类）

在对话系统领域，AdapterCL 是相关工作，它冻结预训练模型并为每个任务学习适配器。相比之下，本文方法参数更高效，且探索了双向迁移。回放、正则化、结构扩展三类路线

##### 3.2、Prompt-based Tuning（基于提示的调优）:

 • 手动设计提示或自动生成提示

 • 离散空间搜索次优，因此出现软提示（嵌入可学习）

 • Prompt Tuning：冻结预训练模型，只调优软提示，参数高效且随模型规模增大更具竞争力

• 与嵌入适配器（Adapter）的区别：适配器转换所有 token 嵌入但不影响 Transformer 层；提示调优不改变 token 嵌入，而是添加新的可学习提示 token 作为上下文，影响后续所有层

##### 3.3、Dialog State Tracking（对话状态追踪）：

 • 传统基于本体的方法需要访问所有候选值

 • 为缓解对本体依赖并提升泛化能力，出现基于抽取和基于生成的方法

• 生成模型又分为：一次性生成所有 slot-value 对（高效但缺乏迁移性），或为每个 slot 单独生成值（可融入 slot 描述信息）

 • 本文方法结合两者优点：将多个 slot 描述整合为单次查询，一次性生成所有值

#### 4、方法

##### 4.1 Continual Prompt Tuning 核心机制：冻结T5；每项服务保存一段独立软提示

DST改写：对话+槽位描述+哨兵标记  一次生成全部槽位值

直接效果:旧服务提示不再更新，因此不被新任务覆盖

##### 4.2 前向迁移:旧任务如何帮助新任务?

CLlnit：上一任务的提示初始化当前任务

Query Fusion：混合不同服务的槽位描述，学习通用“描述一取值”关系 

Memory Replay:少量旧样本参与训练，补充已有知识

##### 4.3 后向迁移：新任务如何帮助旧任务

为旧任务创建候选提示，并用当前任务数据尝试更新

用旧任务记忆样本检查:会损害旧任务的更新直接舍弃

只保留性能不退化且更优的候选提示

#### 5、总结

1. 首次将提示调优应用于持续学习，通过冻结主干模型、只训练少量提示 token，高效避免了灾难性遗忘
2. 提出了多种前向迁移技术（持续提示初始化、查询融合、记忆回放）和后向迁移技术（记忆引导更新）
3. 在持续 DST 上的大量实验证明了方法相比现有最优基线的优越性能和效率
4. 该方法和发现将推动构建更具可扩展性、适应性的任务型对话系统
